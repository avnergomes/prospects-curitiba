## Sobre

Cada mock é construído a partir de dados públicos do estabelecimento (Google Maps): endereço, telefone, horário, avaliações reais, fotos do interior. O objetivo é mostrar como ficaria um site institucional simples, sem custo recorrente de hospedagem.

**Stack técnica:** HTML estático + Tailwind via CDN. Single file por mock. Sem build step. Hospedagem em GitHub Pages.
